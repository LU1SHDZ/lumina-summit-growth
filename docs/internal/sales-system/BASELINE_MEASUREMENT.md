# Baseline measurement

## Principle

Measure from the most reliable evidence currently available, label confidence, and improve data quality over time. Do not reconstruct false precision.

## Core funnel definitions

For each client, explicitly define acquisition source, inquiry, qualified inquiry, scheduled appointment/inspection/estimate, attended appointment, proposal/estimate, won customer/job, lost opportunity, revenue, and repeat/referral customer.

## Baseline table

Capture value, period, source, owner, confidence, known gaps, and whether the definition changed. Where data is unavailable, record “unavailable” instead of zero.

## Reconciliation

- Compare web forms, calls, messages, booking tools, and CRM/spreadsheet records.
- Identify duplicate, spam, existing-customer, vendor, and out-of-scope contacts.
- Preserve original source when possible; document attribution rules.
- Note seasonal and capacity conditions that make periods non-comparable.

Baseline improvement is itself a deliverable when reliable measurement did not previously exist.
