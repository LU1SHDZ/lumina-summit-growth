# Sales and delivery operating system

Working lifecycle:

1. Application received
2. Human qualification review
3. Discovery call
4. Diagnostic preparation
5. Proposal and agreement
6. Client onboarding
7. Baseline confirmation
8. Local Growth Foundation Sprint
9. 30/60/90-day roadmap
10. Measurement and reporting
11. Case-study/referral review when appropriate

These files are operating drafts, not approved legal agreements or promises. Founder decisions in `FOUNDER_DECISIONS.md` take precedence where a commercial choice is unresolved.
