# Internal operating documentation

This directory contains non-public business processes and working templates. It is intentionally outside `public/` and has no application routes. Do not place client secrets, credentials, raw exports, personal data, signed agreements, or completed client reports in Git.

- `sales-system/` — prospect-to-client and client-delivery workflows.
- `analytics/` — provider-neutral event and measurement architecture.
- `../audit-framework/` — evolving diagnostic method and blank client-report template.
