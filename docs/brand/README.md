# Lumina Summit Growth logo

The current logo was selected and supplied by founder Luis Hernandez. It combines:

- illuminated mountain and sunrise imagery for **Lumina** and **Summit**;
- a golden-ratio construction that reinforces deliberate progress;
- restrained geometric detailing and earth tones that complement Lumina’s culturally grounded visual direction.

The website preserves the founder-supplied artwork without AI reinterpretation.

## Files

- `public/images/brand/lumina-summit-growth-logo.png` is the exact founder-supplied master used by the website.
- `public/images/brand/lumina-summit-emblem-v3.png` is a compact crop of the same master for navigation-size use.
- `components/brand/brand-lockup.tsx` places the compact emblem beside live, accessible company text.
- `app/icon.png` is a resized derivative used as the browser/app icon.

The mark is a working identity and can be refined with a professional identity designer before trademark filing or broad commercial use.
