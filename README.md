# Lumina Summit Growth

Premium, AI-powered growth agency website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run `npm install`.
3. Run `npm run dev`.

The initial milestone implements the homepage. Service, contact, and free-audit routes are intentionally reserved for the next milestone.

## Structure

- `app/` — routes, global styles, metadata
- `components/` — composable page sections, layout, UI, and SEO components
- `lib/` — data/constants shared across components
- `types/` — shared TypeScript contracts
- `hooks/` — future reusable React behavior
- `public/` — static media and social preview assets
- `styles/` — future modular design-system styles
